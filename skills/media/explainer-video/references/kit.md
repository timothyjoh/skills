## Layout

```
<project>/
  script.json                 the script (say/show per line), written by you
  scores/<style>.json         one score per style, written by you (references/audio.md)
  src/data/project.json       size, fps, duration, styles, mix levels (tools keep it updated)
  src/data/beats.json         one entry per script line: index, say, show, start, end (seconds)
  src/data/words.json         every spoken word: text, start, end, beat
  src/data/captions.json      caption pages (2 or 3 words, digits as shown)
  src/styles/<style>/Scene.tsx  the scene for one style; put helpers beside it
  src/styles/index.ts         registry, generated by new-project.mjs
  src/lib/                    the shared kit below (refreshed from the skill on re-scaffold)
  tools/                      narrate.mjs, synth.mjs, render.mjs
  public/audio/               narration.wav and <style>/{music,sfx}.wav
  out/                        stills, films, compare.mp4, compare.html
```

Each style is its own Remotion composition with the id of the style. A scene component takes no props: it reads the frame with `useCurrentFrame()`, the size with `useVideoConfig()`, and the story from the timeline. The soundtrack is added around it, so a scene never adds the narration or music itself.

## Timeline: src/lib/timeline.ts

Every event is keyed to the narration. Times in the JSON are seconds; every helper returns frames.

| Export | Use |
|---|---|
| `at(word, { beat?, nth? })` | Frame where a spoken word starts. Throws when the word is missing, so a typo fails loudly. Use `beat` when the word repeats across lines. |
| `atEnd(word, opts)` | Frame where that word ends. |
| `beatRange(i)` | `{ from, to, dur }` frames of script line i. One shot per beat is the default structure. |
| `beatAt(frame)` | `{ index, local, progress }` for the beat playing now. |
| `sec(s)` | Seconds to frames. |
| `beats`, `words` | The raw arrays. |

Typical scene shape:

```tsx
const frame = useCurrentFrame();
const { index, local, progress } = beatAt(frame);
// pick the shot for this beat, animate within it with `local` / `progress`
const counterIn = at("twelve", { beat: 1 });
const s = pop(frame, counterIn, 9);
```

Without narration (`narrate.mjs --silent`) there are no words; key events to `beatRange(i)` and frame offsets.

## Motion: src/lib/motion.ts

| Export | What it does |
|---|---|
| `prog(frame, from, dur)` | 0..1 progress, clamped. |
| `smoothstep`, `smootherstep`, `easeOutCubic`, `easeInOutCubic`, `backOut` | Easing curves on 0..1. |
| `pop(frame, from, dur)` | Back-eased 0 to 1 scale for an element popping in. |
| `onN(frame, n)` | Hold drawings: `onN(frame, 2)` animates on twos, `onN(frame, 3)` on threes. |
| `kick(frame, at, len, amp)` | Decaying shake offset for a camera kick on a hit. |
| `rng(seed)` | Seeded random sequence. |
| `hash(...ints)` | Stable 0..1 value per element and per drawing, for jitter and boil. |
| `lerp`, `remap`, `clamp` | Arithmetic. |

Hand-drawn boil: re-seed shape jitter with `hash(elementId, onN(frame, 3))` so lines wobble once per drawing, not every frame.

## Captions: src/lib/Captions.tsx

`<Captions />` draws the current page from `captions.json`: Poppins Bold, white with a black outline, the spoken word in yellow `#E3E302`, near the bottom. Props change the look: `fontFamily`, `fontWeight`, `size`, `color`, `highlight`, `outline`, `outlineWidth`, `bottom` (fraction of height). `renderPage(page, activeIndex, t)` replaces the drawing entirely (cut-paper letters, chalk, brush), and `pageAt(t)` gives the same data for captions drawn inside a canvas or 3D scene. Load other fonts with `@remotion/google-fonts/<Family>` at module scope. Put `<Captions />` last in the scene so it sits on top. When `project.captions` is false it draws nothing.

## 2D: Canvas2D and makeLayer

- `<Canvas2D draw={(ctx, frame, { width, height }) => ...} />` is a full-frame canvas redrawn from scratch every frame.
- `makeLayer(w, h)` returns `{ canvas, ctx }` for an offscreen layer: printing plates, paper pieces, cels, sprite sheets, masks. Create layers once with `useMemo`, draw them every frame (or every second or third frame for work on twos or threes), and composite them with a `ShaderPass`.
- SVG is just React: `<svg>` with paths, gradients and filters (`feTurbulence` + `feDisplacementMap` for brushed edges) is often the quickest route for flat motion graphics.

## Shaders: ShaderPass

`<ShaderPass fragment={GLSL} layers={[canvasA, canvasB]} paint={(frame) => drawLayers(frame)} uniforms={{ uInk: [0.1, 0.1, 0.12] }} />`

One full-screen fragment shader. It receives `vUv` (0..1, origin bottom-left), `uTime` (seconds), `uFrame`, `uResolution` (px), `uTex0`..`uTex7` (the layers, in order) and any numeric or vector uniforms you pass. `paint(frame)` runs before each frame is drawn, so draw the layers there. Use it to print flat layers with a medium (misregistration, halftone, paper tooth, grain) or to draw a whole world with one signed-distance-field raymarcher. Layers are uploaded upright: `texture2D(uTex0, vUv)` shows the canvas the way it was drawn.

## 3D: ThreeCanvas and FilmPass

```tsx
import { ThreeCanvas } from "@remotion/three";
<ThreeCanvas width={width} height={height} camera={{ fov: 35, position: [0, 2, 8] }} shadows>
  <MyWorld />
  <FilmPass bloom={0.5} focus={6} aperture={12} vignette={0.4} grain={0.25} />
</ThreeCanvas>
```

- Drive everything from `useCurrentFrame()` inside the canvas. Set the camera with `const cam = useThree((s) => s.camera)` and position it in render.
- `FilmPass` (src/lib/FilmPass.tsx) renders the scene to an HDR target and applies one film shader: `bloom`, `bloomThreshold`, `focus` (world units from the camera), `aperture` (blur px, 0 = off), `aberration`, `vignette`, `grain`, `shadowTint`, `highlightTint` (split-tone grade as RGB 0..1), `saturation`, `exposure`, `letterbox` (for example 2.39). Extend it for a style-specific pass (ink edges from depth, anamorphic streaks, god rays) by copying it beside the scene and adding to the shader.
- Large counts of the same object: `THREE.InstancedMesh`, matrices set every frame, `frustumCulled = false` on anything that moves.
- Toon shading: `MeshToonMaterial` with a 2- or 3-step gradient map (`DataTexture`, `NearestFilter`). Ink outlines: an inverted-hull copy (`BackSide`, slightly scaled, flat ink colour) or an edge pass on depth in a copied FilmPass.
- Text in 3D: draw it into a canvas and use a `CanvasTexture` on a plane, or keep text in the HTML/SVG layer above the canvas.
- Shadows: three 0.187 removed `PCFSoftShadowMap`; the default `PCFShadowMap` or `VSMShadowMap` work.

## Rules every scene follows

- Every frame is a pure function of the frame number. No `Math.random`, `Date.now`, timers, `useFrame` deltas or state carried from frame to frame. Use `rng(seed)` and `hash(...)`.
- No image files, textures from disk, models or video. Everything is drawn: SVG, canvas, shaders, geometry.
- No real logos, brands or trademarked characters; original designs only.
- Keep anything that matters inside the frame for the whole move, and inside the caption-safe area (the bottom 25 percent on vertical belongs to captions).
- When the aspect ratio is not the one a style describes, recompose: wide frames stage subjects side by side, tall frames stack them. Never just crop.

## Known problems

- `@react-three/postprocessing`'s `EffectComposer` rendered black frames under Remotion in testing (2026-11-20). Use `FilmPass`.
- `THREE.Clock` deprecation warnings in the render log are harmless.
- `npm install` may warn that install scripts were skipped (onnxruntime-node, sharp, protobufjs). Narration still worked in testing; if `narrate.mjs` fails to load the voice model, run `npm install-scripts approve onnxruntime-node` in the project and install again.

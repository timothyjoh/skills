# Development

Delegating work to project agents and collecting their results, and explaining and reviewing code changes.

## Model-invoked

- **[t3-handoff](./t3-handoff/SKILL.md)**: Hand off a task to a registered T3 Code project, follow its progress reports, and collect the agent's result.
- **[t3-report](./t3-report/SKILL.md)**: Send progress reports from a delegated T3 session back to the coordinator that started it.
- **[explain-pr](./explain-pr/SKILL.md)**: Explain a PR or commit range as a staff-engineer brief, with every code link checked against the pinned commits.
